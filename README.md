# Interview warm-up

This is a practice workspace so the interview editor feels familiar.
Nothing here is assessed and nobody sees what you do.
It takes about 10 minutes.

## Open it

Click **Code**, then **Codespaces**, then **Create codespace on main**.
You need a GitHub account.
Setup takes a minute or two; wait until the terminal stops printing.

## Try these

1. **Run the tests.** In the terminal (**Terminal**, **New Terminal**) run:

   ```sh
   .venv/bin/python -m pytest -v
   ```

   All 5 tests fail with `NotImplementedError`. That is expected.
2. **Use the Testing sidebar.** Click the flask icon on the left to run or debug a single test.
3. **Fix a test.** Implement `running_total` in `warmup.py` and rerun. Two tests should now pass.
4. **Split the editor.** This page is open beside `warmup.py`. Drag a tab to a different side to rearrange.
5. **Try the debugger.** Click left of a line number to set a breakpoint, then debug a test from the Testing sidebar.
6. **Try Live Share.** Click **Live Share** in the status bar (bottom left) and sign in when asked.
   In the interview, the interviewer will send you an invitation link and you join from your browser.
   Signing in now saves time on the day.

If something does not work, tell the interviewer before the interview.

When you are done, delete the codespace at [github.com/codespaces](https://github.com/codespaces).
